# 出荷状況ダッシュボード

仕入れ（マレーシア）の最新ETDと、営業のステータスレポートを照合し、
スケジュールの不一致と、出荷済ブッキングの船の進捗を確認するための社内ツールです。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | 見た目（ダークモード対応） |
| `app.js` | CSVの読み込み・照合・表示のロジック |
| `vercel.json` | Vercelの設定（検索エンジン除外、セキュリティヘッダー） |
| `sample-data/` | 動作確認用のダミーCSV（実データではありません） |

ビルド不要の静的サイトです。インストールするものはありません。

## 使い方

1. 画面の「営業ステータスレポート」にCSVを選択（または貼り付け）
2. 「仕入れ最新スケジュール」にCSVを選択（または貼り付け）
3. 「更新して照合」を押す

CSVの列名（1行目）は次のとおりです。

- 営業：`booking, cy, qty, etd`
- 仕入れ：`booking, etd, vessel, location, eta`

日付は `2026-10-28` または `2026/10/28` の形式です。

照合のルール：ETDは仕入れ側を正とし、営業側と日付が違えば「不一致」、
どちらか片方にしかないブッキングも「不一致」として赤く表示します。
出荷済は「最新ETDが今日以前」で判定します。

## 手元で動かす

`index.html` をブラウザで開くだけで動きます。

## GitHub → Vercel で公開する手順

### 1. GitHubに上げる（プライベート）

1. GitHubで **New repository** → 名前（例：`shipping-dashboard`）→ **Private** を選んで作成
2. 作成後の画面で **uploading an existing file** を選び、このフォルダの中身をすべてドラッグ＆ドロップ
3. **Commit changes** を押す

### 2. Vercelにつなぐ

1. Vercelにログインし **Add New → Project**
2. GitHubと連携し、上記のリポジトリを **Import**
3. 設定は変更せず（Framework Preset は `Other`、Build Command は空）**Deploy**
4. 発行されたURLでダッシュボードが開きます

以降は、GitHubのファイルを更新すると自動でサイトも更新されます。

## 社内展開の前に必ず確認すること

- **実データをGitHubに上げない**：`real-data/` フォルダは `.gitignore` で除外済みです。
- **閲覧制限**：URLを知っていれば誰でも開ける状態がデフォルトです。
  取引情報を扱うため、ログイン必須の設定（Vercelの保護機能や社内SSO）が使えるか、
  システム部門に確認してください。プランによって使える機能が異なります。
- 現状は、読み込んだCSVは各自のブラウザ内だけで処理され、**サーバーには保存されません**。
  営業の更新内容を仕入れ側と共有するには、次の段階でデータ保存が必要です。
